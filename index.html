메시지로 기록하고,
하루를 준비하세요.

메모, 지출, 일정과 리마인더를 텔레그램 개인 대화로 관리하는 개인용 비서입니다. 운영자 본인이 사용하는 앱으로, 공개 회원가입은 제공하지 않습니다.

현재 제공하는 기능

말로 남기는 일상의 기록

본인의 텔레그램 계정과 연결한 뒤, PC 또는 개인 서버에서 실행합니다.

01

메모와 가계부

기억할 내용을 저장하고 지출을 기록합니다. 저장된 기록 조회와 월별 지출 합계를 지원합니다.

“점심 12,000원 썼어”
02

일정과 리마인더

봇에 일정을 기록하고 지정한 시각에 알림을 받습니다. 현재 일정은 봇의 데이터베이스에 저장됩니다.

“30분 뒤에 빨래 알려줘”
03

자연어 대화와 웹 요약

Claude API로 요청을 해석하고 공개 웹페이지를 요약합니다. 모호한 일정이나 수정 대상은 대화로 확인합니다.

“이 글 핵심을 정리해줘”

다음으로 준비하는 기능

내 캘린더에서
오늘의 브리핑까지.

Google Calendar OAuth 연결과 아침 브리핑을 준비하고 있습니다. 현재는 Google 계정 연결과 일정 접근이 활성화되어 있지 않습니다.

Google Calendar 연동 준비 중
  1. 1

    본인이 직접 연결 승인

    Google 로그인 화면에서 캘린더 권한을 확인하고 승인합니다.

  2. 2

    전용 캘린더에 일정 등록

    앱이 만든 ‘개인비서’ 캘린더를 관리하고, 브리핑에 사용할 기존 캘린더를 선택합니다.

  3. 3

    오전 8시에 하루 확인

    오늘 일정을 조회해 본인의 텔레그램 개인 대화로 전달하는 기능을 구현할 예정입니다.

데이터를 이해하고 사용하기

어디에 저장되고,
누구에게 전달되나요?

기록은 운영자의 PC 또는 서버에 저장됩니다. 자연어 기능에서는 요청과 관련된 대화·기록이 Anthropic의 Claude API로 전송되고, 답변과 알림은 Telegram을 통해 전달됩니다.

이 안내 사이트에는 로그인이나 데이터 입력 기능이 없으며, 실제 일정·메모·인증 토큰을 게시하지 않습니다.
