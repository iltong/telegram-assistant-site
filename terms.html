이 약관은 iltong이 운영하는 텔레그램 개인비서의 사용 범위와 운영 원칙을 설명합니다. 앱은 운영자 본인이 사용하는 개인 프로젝트이며 공개 가입이나 유료 구독 상품을 제공하지 않습니다.

Google Calendar OAuth 연동과 오전 8시 브리핑은 준비 중입니다. 사이트의 예시 화면은 실제 이용자의 일정이 아니며, 기능 제공이 완료되었다는 의미가 아닙니다.

1. 제공 범위

현재 봇은 텔레그램 개인 대화를 통한 메모·가계부·로컬 일정·리마인더 관리와 공개 웹페이지 요약을 지원합니다. 자연어 해석에는 Claude API를 사용합니다. Google 계정 연결은 관련 기능이 구현되고 본인이 접근 권한을 승인한 후에만 가능합니다.

공개 안내 사이트는 기능과 데이터 처리 방식을 설명하는 페이지이며 봇 실행, Google 로그인 또는 일정 입력을 제공하지 않습니다.

2. 계정과 인증 정보

사용자는 본인이 관리하거나 사용 권한을 가진 계정·서버만 연결합니다. API 키와 토큰을 안전하게 보관하고 공개 저장소·문의 게시판에 올리지 않습니다. Google 권한은 사용자가 직접 승인하며, 승인하지 않은 권한이 필요한 기능은 사용할 수 없습니다.

3. 처리 결과와 알림

AI가 해석한 날짜, 시간, 금액 및 변경 대상을 확인하세요. 서버 중단, 네트워크 문제, 외부 API 제한에 따라 응답이나 알림이 지연·누락되거나 재시도로 중복될 수 있습니다. 중요한 예약과 마감은 원본 캘린더와 별도 알림으로 함께 확인하는 것을 권장합니다.

4. 외부 서비스와 비용

Telegram, Google 및 Anthropic의 서비스 이용에는 각 제공자의 약관과 정책이 적용됩니다. 서버·네트워크·Claude API 등의 사용료는 각 서비스 계정의 이용 조건에 따라 발생할 수 있습니다. 이 공개 안내 사이트는 결제 정보를 수집하거나 별도의 이용료를 청구하지 않습니다.

이 앱은 Google, Telegram 또는 Anthropic이 제공하거나 보증하는 공식 제품이 아닙니다.

5. 데이터 관리와 이용 중단

데이터 접근·전달·보관·삭제는 개인정보처리방침을 따릅니다. 봇에서 항목을 삭제해도 처리 이력과 백업에 사본이 남을 수 있으므로, 전체 삭제를 원하면 관련 사본까지 관리해야 합니다.

운영자는 봇을 종료하여 사용을 중단할 수 있으며, Google 연결 후에는 Google 계정에서 접근 권한을 철회할 수 있습니다. 봇 종료나 권한 철회만으로 기존 일정·메모·대화·백업이 자동 삭제되지는 않습니다.

6. 변경과 문의

기능과 운영 방식은 개인 프로젝트의 개발 상태에 따라 바뀔 수 있습니다. 중요한 변경은 안내 사이트 또는 봇에서 알리고, 개인정보 처리 범위가 달라지면 관련 방침과 필요한 동의 절차를 갱신합니다.

일반 문의: GitHub Issues. 공개 게시판이므로 개인정보와 인증 정보를 포함하지 마세요.
