이 방침은 iltong이 운영하는 1인용 앱 텔레그램 개인비서와 공개 안내 사이트에 적용됩니다. 앱은 운영자 본인이 사용하는 텔레그램 봇이며, 불특정 다수의 회원가입을 받지 않습니다.

Google Calendar 연동은 준비 중입니다. 현재 공개 안내 사이트와 미연결 봇은 Google 계정에 접근하지 않습니다. 아래 Google 관련 내용은 연동 기능에 적용할 처리 범위이며, 기능 구현과 데이터 처리 확인을 마친 뒤 본인의 OAuth 승인을 받아 연결합니다.

2. Google 계정 연결과 권한

Google 계정 비밀번호를 봇에 입력하지 않습니다. Google의 로그인·동의 화면에서 권한을 승인하는 OAuth 방식을 사용합니다. 운영자 본인이 연결한 계정과 선택한 캘린더를 대상으로 기능을 제공할 예정입니다.

  • 앱이 만든 캘린더 관리: ‘개인비서’ 전용 캘린더 생성과 해당 캘린더의 일정 조회·등록·변경·삭제에 사용합니다.
  • 기존 캘린더 일정 읽기: 선택한 캘린더의 일정을 조회해 브리핑에 포함합니다. 기존 캘린더의 일정을 수정하는 권한은 요청하지 않습니다.
  • 캘린더 목록 읽기: 브리핑에 사용할 캘린더를 선택하는 데 사용합니다.

Google의 일정 읽기 권한 자체는 계정이 접근할 수 있는 여러 캘린더에 적용될 수 있습니다. 앱의 실제 조회 대상은 사용자가 선택한 캘린더로 제한하도록 구현합니다. 권한을 거부하면 해당 권한이 필요한 기능을 사용하지 않습니다.

Google API로 받은 정보는 사용자가 요청한 일정 관리·조회·브리핑에만 사용합니다. 운영자는 이 정보를 판매하거나 광고 타기팅, 감시 또는 범용 AI 모델 학습에 사용하지 않습니다. 필요한 기능 제공을 위한 전달은 다음 항목에 설명합니다.

텔레그램 개인비서는 Google API에서 받은 정보를 사용할 때 Google API Services User Data Policy와 그 Limited Use 요건을 준수합니다.

3. 외부 서비스로 전달되는 정보

  • Telegram: 사용자가 보낸 메시지, 봇의 답변·알림과 요청한 내보내기 파일을 처리합니다. 연동 후에는 브리핑에 포함한 일정 정보도 본인의 개인 대화로 전달됩니다. Telegram 봇 대화는 비밀대화가 아닙니다.
  • Anthropic / Claude API: 자연어 요청을 해석할 때 메시지, 최근 대화와 도구가 반환한 관련 메모·지출·일정 등의 내용이 전송됩니다. 명시 명령의 결과도 이후 자연어 대화 문맥에 포함될 수 있습니다. 웹 요약에는 요청한 URL·제목·본문 일부가 전달됩니다. Google 연동 후 AI를 사용하는 일정 대화나 브리핑에는 필요한 일정 정보가 전송될 수 있으며, 연결 시 이 전달 방식을 안내합니다. Google 비밀번호와 OAuth 토큰은 AI 입력에 포함하지 않는 방식으로 구현합니다.
  • Google: OAuth 인증과 Calendar API 요청을 처리합니다. 연결 후 사용자가 요청한 일정 내용은 전용 Google 캘린더에 저장됩니다.
  • Google Cloud 또는 운영자가 선택한 서버: 봇의 실행 환경과 데이터 저장 공간을 제공합니다. 현재 배포 대상은 운영자의 Google Cloud VM입니다.

운영자는 요청한 기능 제공에 필요한 범위에서 서비스를 사용합니다. 각 서비스에서의 처리와 보관에는 해당 제공자의 약관·개인정보 정책이 적용되며, 운영자가 모든 제공자의 기록을 직접 삭제하거나 보관 기간을 보장할 수는 없습니다.

제공자 정책: Telegram · Anthropic API 약관 및 데이터 처리 조건 · Google

4. 저장과 보관 기간

봇의 기록·대화 처리 이력·예약 상태는 운영자의 PC 또는 VM의 SQLite 데이터베이스에 저장됩니다. DB 자체 암호화는 현재 사용하지 않으며 운영체제 계정과 파일 접근 권한으로 보호합니다.

현재 데이터에 일괄적인 자동 보관 만료 기간은 없습니다. 운영자가 삭제할 때까지 DB, 응답·실행 이력, 내보낸 CSV, 자동 백업과 업데이트 복구용 백업에 정보가 남을 수 있습니다. 백업과 내보내기 파일은 자동 삭제되지 않습니다.

인증 정보는 공개 소스·안내 사이트와 분리해 보관합니다. Google OAuth 토큰의 구체적인 저장·삭제 절차는 연결 기능과 함께 제공하고, 사용을 시작하기 전에 확인할 수 있도록 안내합니다.

5. 삭제와 연결 해제

  • 봇의 개별 항목 삭제는 해당 기록과 연결된 예약을 삭제합니다. 이미 만들어진 대화·응답·실행 이력, 백업, 내보내기 사본까지 모두 지우는 기능은 아닙니다.
  • /reset은 앞으로 사용할 대화 문맥을 초기화합니다. 저장된 전체 기록이나 실행 이력을 완전히 삭제하는 명령이 아닙니다.
  • 운영자가 완전한 로컬 삭제를 원하면 봇을 종료한 뒤 DB와 관련 백업·내보내기·운영 로그의 사본을 확인하여 직접 삭제해야 합니다. 복구용 백업에도 이전 데이터가 포함될 수 있습니다.
  • Google 연결 후에는 Google 계정의 연결된 앱 관리에서 권한을 철회할 수 있습니다. 권한 철회는 이후 접근을 제한하며, Google 캘린더에 이미 저장한 일정이나 로컬 사본을 자동으로 삭제하지 않습니다.
  • Telegram 대화와 파일은 Telegram에서 별도로 삭제하고, Google 캘린더에 생성한 일정·전용 캘린더는 Google Calendar에서 별도로 관리합니다.

6. 이 안내 사이트의 데이터 처리

이 사이트는 정적 안내 페이지입니다. 회원가입, Google 로그인, 개인 일정 입력, 광고, 운영자가 설치한 방문 분석 도구 또는 쿠키를 사용하지 않습니다. 외부 폰트·이미지를 불러오지 않습니다.

호스팅 제공자인 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요. 외부 링크를 누르면 해당 서비스의 정책이 적용됩니다.
